# Event Ledger

A distributed Event Ledger system implemented using Java and Spring Boot.

The system will consist of two independently runnable services:

- **Event Gateway** — public-facing API for receiving and retrieving transaction events
- **Account Service** — internal service responsible for account balances and transaction history

## Technology stack

- Java 21
- Spring Boot
- Maven
- H2
- Docker Compose

## Project status

Project foundation is being established. Application services have not yet been implemented.
